# Public Trainer Profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a public, shareable trainer page at `/trainer/{pseudo}` with an opt-out privacy toggle in `/me`.

**Architecture:** New `trainers` NestJS module (hexagonal: `trainers.db.ts` + `trainers.service.ts`) composes existing Dex/Manholes/Achievements/Favorites services to return a public `TrainerProfile`. A new SvelteKit route `/trainer/[pseudo]/+page.svelte` renders it client-side. A `publicProfile Boolean` column on `User` gates visibility; private profiles return `404` (indistinguishable from missing — no info leak). A third throttler tier (`trainer-public`, 60/min/IP) protects the anonymous endpoint.

**Tech Stack:** NestJS 10 · Prisma 5.22 · `@nestjs/throttler` 6 · SvelteKit 2 + Svelte 5 runes · `@tanstack/svelte-query` v5 · Tailwind.

**Spec:** [docs/superpowers/specs/2026-05-20-public-trainer-profile-design.md](../specs/2026-05-20-public-trainer-profile-design.md)

**Repo conventions you MUST follow (from `~/.claude/CLAUDE.md`):**
- Hexagonal split. Every DB-touching module has `*.service.ts` (no Prisma import) + `*.db.ts` (only Prisma importer). Both registered as providers.
- Explicit return types on every backend function/method (eslint enforces; even `Promise<void>`).
- No single-letter local variables. Use `const manhole = …`, not `const m = …`. `i/j/k` allowed only in indexed `for` loops.
- No inline `if` — brace + body on its own line.
- Blank line before `if`, `for`, `while`, `return`, `throw` (unless first statement in its block).
- No `!!x` double-negation — use `x != null` or `Boolean(x)`.
- Exact-pinned npm deps (no `^` / `~`). N/A in this plan since no deps are added.

**No automated tests in this repo.** Verification is `npm run build` + `curl` + manual UI check, matching prior plans (favorites, landing). Each task ends with a commit.

import { Injectable, NotFoundException } from '@nestjs/common';
import { UserPublic } from '@dexkepo/shared';
import { UserRow, UsersDb } from './users.db';
import { UpdateProfileDto } from './dto/update-profile.dto';

@Injectable()
export class UsersService {
  constructor(private db: UsersDb) {}

  async me(id: string): Promise<UserPublic> {
    const row = await this.db.findById(id);

    if (!row) {
      throw new NotFoundException('user not found');
    }

    return toPublic(row);
  }

  async updateProfile(id: string, patch: UpdateProfileDto): Promise<UserPublic> {
    const row = await this.db.updateProfile(id, patch);

    if (!row) {
      throw new NotFoundException('user not found');
    }

    return toPublic(row);
  }
}

function toPublic(row: UserRow): UserPublic {
  return {
    id: row.id,
    pseudo: row.pseudo,
    email: row.email,
    publicProfile: row.publicProfile,
    createdAt: row.createdAt.toISOString(),
  };
}

```ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { TrainerProfile } from '@dexkepo/shared';
import { DexService } from '../dex/dex.service';
import { ManholesService } from '../manholes/manholes.service';
import { AchievementsService } from '../achievements/achievements.service';
import { FavoritesService } from '../favorites/favorites.service';
import { TrainersDb } from './trainers.db';

@Injectable()
export class TrainersService {
  constructor(
    private db: TrainersDb,
    private dexSvc: DexService,
    private manholesSvc: ManholesService,
    private achievementsSvc: AchievementsService,
    private favoritesSvc: FavoritesService,
  ) {}

  async profile(pseudo: string): Promise<TrainerProfile> {
    const trainer = await this.db.findByPseudo(pseudo);

    // Private and missing share the same 404 — no info leak.
    if (!trainer || !trainer.publicProfile) {
      throw new NotFoundException('trainer not found');
    }

    const [visits, allManholes, achievements, favorites] = await Promise.all([
      this.dexSvc.list(trainer.id),
      this.manholesSvc.list(),
      this.achievementsSvc.publicListForUser(trainer.id),
      this.favoritesSvc.listForUser(trainer.id),
    ]);

    return {
      pseudo: trainer.pseudo,
      memberSince: trainer.createdAt.toISOString(),
      visitedCount: visits.length,
      totalCount: allManholes.length,
      achievements,
      favorites: favorites.favorites,
    };
  }
}
```

```svelte
<script lang="ts">
  import { auth, patchUser } from '$lib/stores/auth';
  import { updateProfile } from '$lib/api/users';

  let saving = $state(false);
  let copied = $state(false);
  let errorMsg = $state('');

  const isPublic = $derived($auth?.user.publicProfile ?? false);
  const profileUrl = $derived(
    $auth ? `${location.origin}/trainer/${$auth.user.pseudo}` : '',
  );

  async function toggle() {
    if (!$auth) {
      return;
    }

    saving = true;
    errorMsg = '';

    try {
      const updated = await updateProfile({ publicProfile: !isPublic });

      patchUser({ publicProfile: updated.publicProfile });
    } catch (err) {
      errorMsg = err instanceof Error ? err.message : 'Could not save';
    } finally {
      saving = false;
    }
  }

  async function copy() {
    try {
      await navigator.clipboard.writeText(profileUrl);
      copied = true;
      setTimeout(() => {
        copied = false;
      }, 1500);
    } catch {
      errorMsg = 'Clipboard unavailable';
    }
  }
</script>

<section class="rounded-2xl bg-white p-4 shadow-sm dark:bg-slate-800">
  <div class="flex items-start justify-between gap-3">
    <div>
      <h2 class="text-base font-extrabold text-slate-900 dark:text-slate-100">
        Public profile
      </h2>
      <p class="mt-1 text-xs text-slate-500">
        Share your dex with a link. Toggle off to keep it private — visitors
        will see a "not found" page.
      </p>
    </div>

    <button
      type="button"
      onclick={toggle}
      disabled={saving}
      class="relative h-6 w-11 flex-shrink-0 rounded-full transition-colors {isPublic ? 'bg-rose-500' : 'bg-slate-300 dark:bg-slate-600'} disabled:opacity-50"
      aria-pressed={isPublic}
      aria-label="Toggle public profile"
    >
      <span
        class="absolute top-0.5 h-5 w-5 rounded-full bg-white shadow transition-all {isPublic ? 'left-[22px]' : 'left-0.5'}"
      ></span>
    </button>
  </div>

  <div class="mt-3 flex items-center gap-2">
    <input
      type="text"
      readonly
      value={profileUrl}
      class="min-w-0 flex-1 truncate rounded-lg border border-slate-200 bg-slate-50 px-2 py-1 text-xs text-slate-700 dark:border-slate-700 dark:bg-slate-900 dark:text-slate-300"
    />
    <button
      type="button"
      onclick={copy}
      disabled={!isPublic}
      class="rounded-lg bg-slate-900 px-3 py-1 text-xs font-bold text-white hover:bg-slate-700 disabled:cursor-not-allowed disabled:opacity-40 dark:bg-slate-100 dark:text-slate-900 dark:hover:bg-white"
      title={isPublic ? 'Copy link' : 'Enable public profile first'}
    >
      {copied ? 'Copied!' : 'Copy link'}
    </button>
  </div>

  {#if errorMsg}
    <p class="mt-2 text-xs text-rose-500">{errorMsg}</p>
  {/if}
</section>
```
